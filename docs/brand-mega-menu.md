# Brands 超级菜单

页首的 Brands 树状菜单区块使用 `Brand logo grid (collection images)` 桌面布局，当前选择后台 `Brands` 菜单（handle：`brands`）。

- 在 Shopify 内容 → 菜单 → Brands 中调整品牌名称、链接和顺序。每个一级菜单项链接到对应的产品系列。
- 在产品 → 产品系列 → 对应系列中上传封面图片，菜单直接读取 `link.object.image`。图片等比完整展示在 54 × 54px 区域中。
- 未上传系列封面或链接不是产品系列时，只显示名称并保留图片位置，不使用首件产品图作为品牌 Logo。
- 桌面每行六个品牌，数量不限于设计稿的十二个；超出面板高度时可滚动。悬停、触控点击、Enter/空格和向下箭头均可展开；Esc 关闭并恢复到触发器焦点。
- 移动端沿用主题现有抽屉及同一菜单数据。

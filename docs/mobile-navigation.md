# Maxbuy 移动导航

按 Figma 节点 `86:3649`（一级菜单）和 `86:3817`（产品系列商品抽屉）实现。复用 Header 区块、后台 Series / Brands 菜单和主题现有开关、滚动锁定及页头高度计算。

## 后台维护

- 页首树状菜单区块采用 `Three-column mega menu` 或 `Brand logo grid (collection images)` 时，启用本次移动导航样式。其他菜单类型继续使用主题原有组件。
- Series 区块标题不占后台菜单层级；其菜单可配置三层。分组在一级抽屉内展开，末级产品系列链接进入商品抽屉。普通页面链接仍直接跳转。
- 商品抽屉读取所选产品系列，按系列排序展示前六件商品；数量、封面、标题、价格、原价、折扣随后台真实数据变化。View More 进入对应产品系列，Shop Now 进入商品详情。
- Brands 与桌面端共用同一菜单及产品系列封面图，默认显示前四个品牌；View More / View Less 切换全部品牌。未上传封面时保留名称，不使用首件商品图代替 Logo。
- 顶部搜索使用 Shopify 原生 GET 搜索；All Categories 进入全部产品系列页面。
- 未配置链接或使用 `#` 的末级分类、页首入口仅展示名称，不产生无意义跳转。当前部分入口尚未配置有效链接，需要运营补充。

## 交互与资源

- 一级使用原生 details/summary 展开，不另建手机菜单。
- 分类和品牌列表使用260ms高度动画，支持中途反向切换；箭头同步旋转。二级抽屉使用320ms左右滑动，一级菜单同步退后/恢复，返回动画结束后再隐藏二级并恢复焦点。
- 跟随系统减少动态效果设置关闭过渡。隐藏抽屉滚动条但保留滚动功能；搜索框聚焦不显示 outline 或额外阴影，保留圆角边框。View More 使用独立1px底线，避免文字下划线与按钮边框叠加。
- 二级请求使用 Shopify Section Rendering，缓存已访问系列，切换、返回、关闭及编辑器卸载时取消未完成请求。
- 二级返回保留一级分类展开状态和滚动位置，并恢复分类焦点；Esc 先返回一级，再关闭主抽屉。Tab / Shift+Tab 在二级可操作元素间循环。
- 无 JavaScript 时产品系列链接仍可正常进入集合页面。
- 自定义 CSS/JS 隔离为 `maxbuy-mobile-*`，沿用现有 Montserrat、Public Sans 资源；League Spartan 来自 Google Fonts 官方仓库并保留 OFL 许可。设计稿中的设备状态栏属于参考画面，不在网页内重建。
